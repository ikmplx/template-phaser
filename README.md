# Шаблон 2D-прототипа

## Как запустить

На компьютере должен быть установлен Python 3. Откройте папку проекта и дважды нажмите **Play.cmd**. Игра откроется в браузере; интернет и дополнительные библиотеки не нужны.

Игра открывается по адресу http://127.0.0.1:8000/. Если порт занят, закройте окно другого сервера и повторите запуск. Во время игры оставьте окно сервера открытым. Закончив, закройте его — сервер остановится. Если браузер не открылся, адрес указан в окне сервера.

На стартовой сцене можно нажимать на фигуры и сбрасывать счётчик кнопкой «Начать заново». Это проверка запуска, а не готовая игра. После изменений, внесённых Codex, обновите страницу браузера.

## Как начать новый эксперимент

Скопируйте папку шаблона, не включая `.git` и `.venv`, и дайте копии новое имя. Откройте её как проект в Codex и опишите механику, которую хотите проверить. После изменений обновите страницу или снова запустите Play.cmd.

Если игра не запускается, передайте Codex текст сообщения об ошибке. Попросите Codex сохранить рабочую версию, когда захотите к ней вернуться.
